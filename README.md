# HIRAD Digital Solutions

Official Monorepo for **HIRAD Digital Solutions** — a Somali digital solutions company delivering enterprise business systems, modern web platforms, brand design, and digital media production.

## 📁 Repository Structure

```
HIRAD-Digital-Solutions/
├── hirad-website/      # Official company website (React 18 + Vite)
├── hirad-bms/          # Business Management System (BMS) frontend portal
├── hirad-bms-api/      # BMS backend REST API (Node.js / Express / MongoDB)
├── vercel.json         # Vercel monorepo configuration for hirad-website
└── package.json        # Root workspace configuration
```

---

## 🚀 Projects Overview

### 1. `hirad-website` — Company Website
- **Tech Stack:** React 18, Vite, Framer Motion, Tailwind utility system, Lucide Icons
- **Features:**
  - Modern, responsive marketing website
  - Portfolio showcasing verified projects (HIRAD BMS, Pharmacy Management, Koryaal Fitness, Al-Cadaala Restaurant)

  
  - Team section featuring the functional leads & core team
  - Service inquiry, interactive consultation forms & dark/light theme

### 2. `hirad-bms` — Enterprise Business Management System (Frontend)
- **Tech Stack:** React, Tailwind CSS, Lucide Icons, Recharts

- **Features:** Centralized dashboard, CRM pipelines, sprint task tracking, financial management & invoices.

### 3. `hirad-bms-api` — Backend API
- **Tech Stack:** Node.js, Express, MongoDB / Mongoose, JWT Authentication
- **Features:** Authentication, role-based access control (RBAC), leads, task management, and invoicing endpoints.

---

## 🛠️ Getting Started Locally

### Running the Website:
```bash
cd hirad-website
npm install
npm run dev
```

### Running HIRAD BMS:
```bash
cd hirad-bms
npm install
npm run dev
```

### Running HIRAD BMS API:
```bash
cd hirad-bms-api
npm install
npm run dev
```
